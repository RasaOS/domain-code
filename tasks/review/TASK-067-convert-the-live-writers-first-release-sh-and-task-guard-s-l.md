# TASK-067: Convert the live writers first: release.sh and task-guard's ledger

**Why.** `release.sh` is the one record writer already producing records in installed projects, and it passes free text through `awk -v` (theme, target, title, the approver, the shipped stamp), which expands `\n` and forges lines. Its title parser uses exact fences. task-guard's change-ledger row carries raw values.

## Acceptance criteria

- [x] A newline or a literal `\n` in `--approved-by` or `RASA_ACTOR` yields exactly one approval line and no forged key.
- [x] No `awk -v NAME="$var"` remains in `release.sh` or `task-guard.sh`.
- [x] Output on a clean `RELEASES.md` is byte-identical to `main`; the file mode is unchanged.

## Notes

- Stabilization plan Step 1 (the plan's TASK-64), renumbered.
- `release.sh`: every value that becomes part of a tracker line (version, id, theme, target, title, approver, tag, sha, date) is checked for control characters before the command's first write; every `awk -v` is ENVIRON; the approver is resolved before the bundle is written (it used to be resolved after the bundle and the state flip, so a bad actor left work bundled with no approval); the Planned→Next flip is an exact-line awk replace instead of a `sed` regex built from the version; rewrites go through a temp file beside the tracker that starts as a copy of it, so the mode survives (it used to become 0600); the title parser is the library's `rfm_title`; its private `rasa_actor` copy is gone.
- Interpretation of "exactly one **Approved.** line": a literal `\n` is kept as text on one line; a real newline in `--approved-by` or `RASA_ACTOR` is refused before anything is written (the identity is never collapsed into a different one, per the spec); a later bundle never adds a second approval line.
- `task-guard.sh`: the shared `rasa_actor`; a refused identity is recorded as refused (the hook never blocks a commit); ledger values are one line each; `_strip_block` keeps the hook file's mode — removing task-guard from a shared pre-commit no longer disables the other hooks in it.
